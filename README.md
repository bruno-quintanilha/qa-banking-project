# 🧪 QA Banking Project

## 📌 Descrição

Projeto de testes de software simulando um sistema bancário, com foco em validação de API, testes manuais e automação.

---

## 🚀 Tecnologias utilizadas

* Postman (testes de API)
* JSON Server (mock de backend)
* Git & GitHub (versionamento)
* Jira (gerenciamento de bugs)
* Gherkin (especificação de testes)

---

## 🧠 Escopo do projeto

O sistema simula operações bancárias básicas:

* Criação de usuários
* Criação de contas
* Transações (depósito)

---

## 🧪 Tipos de testes realizados

* Testes positivos (fluxo completo)
* Testes negativos (validações)
* Testes de regras de negócio

---

## 🐞 Bugs encontrados

* Usuário criado sem email
* Conta criada com usuário inexistente
* Transação com valor negativo
* Transação com conta inexistente

---

## 📂 Estrutura do projeto

* `/bugs` → documentação de bugs
* `/test-cases` → cenários de teste (Gherkin)
* `/backend` → API simulada
* `/postman` → coleção de testes

---

## 🎯 Objetivo

Demonstrar habilidades em QA, incluindo:

* Análise de cenários
* Criação de testes
* Identificação de falhas
* Documentação profissional
